Voices are the recorded sample voices Krystal chose — not browser/robot voices. The four voices marked “clips coming soon” use the same clip names in a different folder; they will be enabled when their recordings are copied in. No browser speech reader is used as the main voice.

“Read: Everything” reads the headings, tools, steps (except step 2, see note), affirmation, reflection and disclaimers. “Read: Ritual only” reads only the ritual steps (opening, method, moon, intention, focus if not personalised, closing) — still skipping step 2, which has no pre-recorded clip.

Voice pitch for recorded audio is implemented as playback speed (0.8–1.2). True pitch-shifting of MP3 clips without processing is not available, so pitch and speed move together here — unlike the Canva browser voices, where pitch was a separate speech setting.

Tap Read Ritual once to start the narration, tap it again to stop it. The narration pauses briefly between sections, and takes a longer 4-second pause after the reflection question, so you have time to reflect before the closing.
